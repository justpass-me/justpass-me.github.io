# JustPass public website

A lightweight public marketing website for JustPass, prepared for GitHub Pages.

## Preview locally

Open `index.html` directly or serve this directory with any static web server.

## Publish

1. Create a new public repository in the `justpass-me` organization.
2. Push the contents of this directory to its `main` branch.
3. In **Settings → Pages**, choose **GitHub Actions** as the source.

The included workflow publishes the site after every push to `main`.

Do not add a `CNAME` file until the `justpass.me` DNS zone has been repaired.
